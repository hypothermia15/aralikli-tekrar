# Herhangi Bir Şeyi (aşağı yukarı) Sonsuza Kadar Nasıl Hatırlarsın?

Aralıklı tekrar, unutma eğrisi ve Leitner kutusu üzerine etkileşimli çizgi öykü. Nicky Case'in [How To Remember Anything Forever-ish](https://ncase.me/remember/) (2018) çalışmasının Türkçe uyarlaması.

**Canlı sayfa:** https://hypothermia15.github.io/aralikli-tekrar/

- Yazan, çizen, programlayan: [Nicky Case](https://ncase.me/)
- Türkçe çeviri: Oğul Can Yurdakul
- Uyarlama: Doç. Dr. Miraç Barış Usta (Kasım 2026)

Özgün çalışma [ncase/remember](https://github.com/ncase/remember) deposundadır. Bu kopyada yalnızca Türkçe sayfa bulunur; yapılan değişikliklerin tamamı [UYARLAMA.md](UYARLAMA.md) dosyasında yazılıdır.

Sayfa eğitim amaçlıdır. Başlıktaki "sonsuza kadar" yazarın şakasıdır. Metinde adı geçen uygulamalar tavsiye niteliği taşımaz.
